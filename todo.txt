- edos_rt/std fork: OpenOptions ignores read/write. OpenFlags has only
  NONE/CREATE/APPEND/TRUNCATE, no access-mode bits, and
  library/std/src/sys/fs/edos.rs only ever sets APPEND and CREATE. So
  .read(true).write(true) sends low bits 0, the kernel correctly decodes
  ReadOnly, and mmap(MAP_SHARED, PROT_WRITE) is refused with EACCES.
  This is what fails mmaptest test 3. Fix: add RDONLY=0/WRONLY=1/RDWR=2
  to OpenFlags and set them from OpenOptions::read/write.

- std fork: decode_error_kind (sys/pal/edos/common.rs) maps only EACCES,
  EEXIST, EINVAL, ENOENT, EPERM. Everything else shows as "uncategorized
  error". Worth covering ENOTDIR, EISDIR, EIO, ENOSPC, EROFS, EPIPE,
  EAGAIN, EINTR at least.
